Accessibility Statement

Last updated: August 3, 2026

Commitment

Haunted Threads aims to provide a keyboard-accessible, readable, responsive simulator interface with clear labels, focus states, status messaging, and reduced-motion support.

Current Features

  • Skip links and semantic page landmarks.
  • Visible keyboard focus styles.
  • Light and dark themes with theme-aware contrast.
  • Responsive mobile layout for the simulator and house graph.
  • Reduced-motion handling for animated effects.

Known Limitations

The house graph is highly visual. Event logs, telemetry, and replay exports provide text alternatives for simulation activity, but the map itself may not communicate every spatial relationship to assistive technology.

Feedback

Before production deployment, replace this section with an accessibility contact email and response timeline. For this project build, report issues through the repository.
