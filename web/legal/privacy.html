Privacy Policy

Last updated: August 3, 2026

Overview

Haunted Threads is a browser interface for a native C ghost-hunting simulation. This policy explains the information the site may process when you run simulations, sign in, save replays, export data, or make a run public.

Information We Process

  • Simulation configuration, including seed, scheduler, navigation mode, and hunter names you enter.
  • Simulation events, summaries, replay metadata, public share tokens, and export files.
  • Account identifiers and session information provided by the authentication provider when sign-in is enabled.
  • Technical request data such as IP address, user agent, timestamps, and security logs generated by hosting infrastructure.
  • Theme preference stored locally in your browser.

How We Use Information

Information is used to run simulations, stream live events, save private replay history for signed-in users, generate exports, support public share links, operate authentication, protect the service, and debug reliability issues.

Sharing

Private runs are intended to remain associated with the signed-in account that created them. If you make a run public or share a public link, anyone with that link may view the replay data exposed by the share route. Authentication and hosting providers may process information as service providers.

Retention

Guest runs are live-only unless saved by the server for operational purposes. Signed-in runs may remain in account history until deleted by the operator or according to the deployed retention policy. Public share links should be revoked when no longer needed.

Children

This site is a general-audience technical simulator and is not directed to children under 13. Do not use the account or public sharing features if you are under 13.

Your Choices

You can run in guest mode, avoid public sharing, revoke public shares when available, clear local theme storage in your browser, and request account or replay data deletion through the project maintainer.
